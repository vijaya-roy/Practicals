# Practical 7: Privacy-Enhancing Technologies

## Aim

To study Privacy-Enhancing Technologies (PETs) such as VPNs, Tor and secure messaging applications and understand their role in protecting user privacy.

## Introduction

Privacy-Enhancing Technologies are tools and techniques designed to reduce the collection, exposure or misuse of personal information while using digital services.

## Major Privacy-Enhancing Technologies

### 1. Virtual Private Network (VPN)

A VPN creates an encrypted connection between a user's device and a VPN server.

**Uses:**
- Protects data on untrusted networks.
- Helps hide the user's IP address from websites.
- Secures internet traffic between the device and VPN server.

### 2. Tor

Tor routes internet traffic through multiple volunteer-operated relays to make it harder to link a user's activity with their IP address.

**Uses:**
- Provides greater online anonymity.
- Helps prevent direct tracking of the user's IP address.
- Can be used to access privacy-preserving services.

### 3. Secure Messaging Apps

Secure messaging applications use encryption to protect messages from unauthorized access.

**Example:** Signal

**Uses:**
- Protects private conversations.
- Uses end-to-end encryption for supported communications.
- Helps protect messages from interception.

## Comparison of PETs

| Technology | Main Privacy Benefit | Limitation |
|---|---|---|
| VPN | Encrypts traffic to the VPN server and hides IP address from websites | VPN provider may have visibility into some traffic |
| Tor | Provides stronger anonymity by routing traffic through multiple relays | Can be slower than normal browsing |
| Secure Messaging | Protects messages using end-to-end encryption | Does not hide all metadata or other device activity |

## Effectiveness

PETs can significantly improve privacy when used correctly, but no single technology provides complete privacy.

- **VPN:** Useful for protecting internet traffic, especially on untrusted networks.
- **Tor:** Useful when stronger anonymity is required.
- **Secure Messaging:** Useful for protecting private communications.

## Privacy Protection Practices

1. Use trusted and reputable privacy tools.
2. Keep applications and operating systems updated.
3. Use strong passwords and multi-factor authentication.
4. Avoid sharing unnecessary personal information.
5. Understand the privacy limitations of each technology.

## Result

VPNs, Tor and secure messaging applications were studied and their role in protecting user privacy was evaluated.

## Conclusion

Privacy-Enhancing Technologies can reduce privacy risks by protecting internet traffic, increasing anonymity and securing communication. However, they should be used along with good privacy practices because no single PET can protect all aspects of a user's privacy.
